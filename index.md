# Welcome to Blendwalker (WIP)
{: .fs-9 }
This page contains a collection of guides and tutorials for creating FFXIV-based projects in Blender—such as an animated short or a render of your character—created or curated by the community.[^not-for-modding]
{: .fs-6 .fw-300 }

[^not-for-modding]: 
    It is *NOT* about bringing things back into FFXIV. Resources for that already exist, such as [XIV Modding](https://xivmodding.com/) and [XIV Mods Guide](https://www.xivmods.guide).

<br>
**We have:**  
🌱 A [beginner's guide]({% link docs/getting_started/index.md %}) to help you get started from scratch  
📃 A [glossary]({% link docs/glossary/index.md %}) for looking up common terms you're unfamiliar with  
📦 A collection of [resources]({% link docs/resources/index.md %}) like assets, references, and addons  
📚 [Guides and Tutorials]({% link docs/tutorials/index.md %}) by the community, and curated external ones  
💌 [Tips]({% link docs/tips/index.md %}) on various parts of production, things that make you go "Oh I didn't know that!"

And all of these things can expand thanks to contributions from the community! If there's something you think should be on here but isn't, [suggest or make it]({% link docs/contributing.md %})!
